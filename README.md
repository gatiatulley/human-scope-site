# Human Scope — personal mirror

Сайт с полным текстом инструкции, полученным от пользователя. `human-original.txt` хранит исходный английский текст без редактирования. `human.txt` отличается только заменой ссылок, которые должны вести на **ваш** сайт. Атрибуция TrueSpace сохранена.

## Быстрая публикация на GitHub Pages

1. Создай **публичный** репозиторий GitHub, например `human-scope-site`.
2. Загрузи **содержимое этой папки**, включая скрытую папку `.github/workflows` (а не ZIP целиком), в корень репозитория. Основная ветка должна называться `main`.
3. Открой **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `Publish Human Scope` автоматически запустится после загрузки в `main`. При необходимости запусти его в **Actions → Publish Human Scope → Run workflow**.
4. После успешной публикации сайт будет по адресу `https://USERNAME.github.io/REPOSITORY/`, текст — `https://USERNAME.github.io/REPOSITORY/human.txt`.
5. На сайте нажми **Copy activation prompt**. Промпт автоматически подставит настоящий URL страницы.

**Собственный домен:** в Settings → Pages добавь домен и настрой DNS по инструкции GitHub Pages. В Settings → Secrets and variables → Actions → Variables добавь переменную `SITE_DOMAIN`, например `human.example.com` (без `https://`); запусти workflow повторно. Иначе ссылки внутри human.txt останутся адресами GitHub Pages.

## Прямое размещение на другом хостинге

Перед загрузкой выполни `python configure.py https://your-domain.example/` и размести `index.html` вместе с `human.txt` по указанному адресу. Файл `human-original.txt` можно не публиковать. На статическом хостинге должен работать обычный GET-запрос `human.txt`.

## Проверка

- На сайте нажми **Open plain-text instructions**, проверь полный конец `ACTIVATION CONFIRMATION`.
- В `human.txt` все ссылки для повторного чтения должны вести на **твой** домен. Упоминание авторов TrueSpace в `ABOUT THIS MODE` оставлено намеренно.
- Все четыре CHECKPOINT должны находиться в тексте и следовать в порядке «живой / текст / без / машины».
- Проверяй активацию в новой беседе с моделью, у которой есть доступ к веб-страницам. Четыре слова сами по себе не гарантируют, что весь текст был прочитан: код публичен и может быть скопирован.

## Ограничения

Веб-сайт не может заставить ChatGPT всегда открывать страницу, сохранять её содержание навсегда или исполнять инструкцию вопреки правилам более высокого приоритета. В некоторых режимах нет доступа к сайтам. Для надёжности важные требования лучше также закрепить в настройках ChatGPT или инструкции проекта.
